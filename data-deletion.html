Removing Uniseq and Your Data

Because Uniseq is a local-first application with no user accounts and no cloud storage, all data deletion is entirely in your hands. This page explains where Uniseq stores data and how to remove it completely.

Good news: Uniseq stores no data on external servers. There is nothing on our end to delete. Everything is on your machine.

What Uniseq Stores Locally

Uniseq creates and uses the following locations on your computer:

  • Your workspace folder: The folder you opened as a workspace. Contains all your .md page and stream files, plus the pages/, assets/, uniseq/, journals/, and diary/ subdirectories. This is your actual content.
  • App config directory: A workspace-page-order.json file that stores your sidebar page ordering. Located in your OS app config folder (see paths below).
  • Workspace cache: A derived index stored alongside the app or in a temp location. It is always reconstructible from your files and contains no original content.
  • The Uniseq application binary itself: Installed via your OS package manager or installer.

App Config Directory Paths

Windows

%APPDATA%\uniseq\

Typically: C:\Users\YourName\AppData\Roaming\uniseq\

macOS

~/Library/Application Support/uniseq/

Linux

~/.config/uniseq/

How to Delete Your Data

Step 1: Back up anything you want to keep

Before deleting, make sure to copy any notes or files you want to preserve. Your workspace folder contains plain Markdown files that can be opened in any text editor — no special export needed.

Step 2: Delete your workspace folder

Delete the folder you opened as a workspace in Uniseq. This removes all your pages, streams, and assets. This step is optional if you want to keep your notes but remove the app.

Warning: Deleting your workspace folder permanently removes all your notes. Make sure you have a backup first.

Step 3: Delete the app config directory

Navigate to the app config directory for your OS (listed above) and delete the uniseq/ folder. This removes the page order store and any cached data.

Step 4: Uninstall the application

Uninstall Uniseq using your operating system's standard uninstall mechanism:

  • Windows: Settings → Apps → Uniseq → Uninstall
  • macOS: Drag Uniseq from Applications to the Trash, then empty the Trash
  • Linux: Use your package manager (e.g., apt remove uniseq or delete the AppImage)

After Deletion

  • No data is retained on our servers — there is nothing for us to clean up
  • You can reinstall Uniseq at any time with a fresh start
  • If you kept your workspace folder, you can reopen it in a fresh install and all your notes will be intact
