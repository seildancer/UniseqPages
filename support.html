Frequently Asked Questions

Q: Where are my notes stored?

By default, all your notes are stored as plain .md (Markdown) files inside the workspace folder you opened — everything lives on your own machine. If you enable the optional Uniseq Sync feature, your notes are additionally stored on our backend (Supabase) and synced across devices. You can also connect a custom backend of your own. For local workspaces, you can find your files at any time using your operating system's file explorer.

Q: What is the difference between Pages and Streams?

Pages live in the pages/ folder and are organized in a hierarchy. Their filenames encode the path (e.g. Work___Projects___Alpha.md for the page at Work → Projects → Alpha).

Streams are date-stamped files (yyyy_mm_dd.md) inside stream folders like journals/ or diary/. They are append-only buckets for daily capture and do not appear in the page tree. Stream pages cannot be referenced via [[wikilinks]].

Q: How do wikilinks work?

Type [[Page Name]] or #Page Name inside any page to create a reference. Uniseq indexes all references and will create an empty target file automatically if the referenced page doesn't exist yet. References inside fenced code blocks are ignored.

Q: Can I use Uniseq with an existing Markdown folder?

Yes. Open any folder as a workspace. Uniseq will scan it and add the reserved folders (pages/, assets/, uniseq/, journals/, diary/) if they are missing. It will not overwrite or modify existing files during this setup.

Q: My page tree isn't updating after I edit a file outside the app.

Uniseq uses a filesystem watcher to detect external changes automatically. If the watcher fails (some network drives and certain OS configurations), it falls back to polling. Try the following:

  • Wait a few seconds — polling has a small delay
  • Use the refresh/reload workspace command in the app
  • Restart the app if the issue persists
Q: I renamed a page and now references to it are broken.

Always rename pages through Uniseq (via the sidebar or rename command) rather than directly in the file system. When you rename through the app, Uniseq automatically updates the page order store and handles the file rename correctly. Manual file renames bypass this logic and may leave stale references.

Q: Where is the page order stored?

Sidebar ordering is saved in workspace-page-order.json inside your OS application config directory (not inside your workspace folder). This means the order is per-device, not synced with the workspace files.

Q: Does Uniseq sync with the cloud?

It depends on which sync mode you use — all are optional:

  • Local only (default): No internet connection required. Everything stays on your machine.
  • Uniseq Sync: An optional built-in feature that stores and syncs your notes via our backend (Supabase). Requires an account. You can delete your content or your account at any time.
  • Custom sync: Connect any backend you own or trust. Your data goes where you point it.

For local workspaces, you can still sync with any file-sync tool you already use (Dropbox, Syncthing, iCloud Drive, OneDrive, git, etc.) — your data is plain Markdown files, so any tool works.

Q: How do I back up my notes?

Copy or sync your entire workspace folder. Every piece of content is a .md file — there is no hidden database to export. A simple zip of the folder is a complete backup.

Q: Can I request new features or report bugs?

Absolutely! Send your feature requests or bug reports to 1004wsh@gmail.com. For bugs, please include:

  • A description of what happened vs. what you expected
  • Steps to reproduce the issue
  • Your operating system and Uniseq version
  • Screenshots or screen recordings if applicable
Q: How do I delete my data?

For local workspaces, you control everything — just delete the workspace folder and app config files. See the Data Deletion page for a full walkthrough.

If you use Uniseq Sync, you can delete individual notes from within the app, or delete your account entirely to permanently wipe all data from our backend. The Data Deletion page covers both cases.
